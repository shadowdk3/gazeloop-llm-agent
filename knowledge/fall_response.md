# Fall Incident Response Policy

## 1. Incident Verification

When a potential fall is detected by a surveillance camera,
the incident must be verified before an alert is classified
as a confirmed fall. A single image may not provide enough
information to determine whether a person has fallen.

When possible, review multiple consecutive frames to determine
whether the person is actually falling, lying on the ground,
or continuing normal activities.

## 2. Immediate Response

If a fall is confirmed, the responsible staff member should
check whether the person requires assistance. The area should
be secured if there is an environmental hazard such as water,
snow, ice, or other slippery surfaces.

The supervisor should be notified according to the workplace
emergency procedure.

## 3. Incident Reporting

A confirmed fall should be recorded in the incident management
system. The report should include the approximate time,
location, observed circumstances, and actions taken.

## 4. False Positives

If the surveillance system incorrectly identifies a normal
activity as a fall, the event should be marked as a false
positive. False-positive events should be retained for
evaluation and model improvement.
